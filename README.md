# Cloud Memory

A modern full-stack app for saving personal memories with photos.

## Features

- Secure user registration and login
- JWT-based authentication with protected routes
- Upload and store memory images using Cloudinary
- Create memories with a title and optional description
- View all saved memories in a responsive gallery dashboard
- Delete memories anytime
- Light and dark mode support
- Clean, modern UI for desktop and mobile
- MongoDB-backed data storage for users and memories

Built with React, Node.js, Express, MongoDB, and Cloudinary.
